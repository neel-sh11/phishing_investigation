Phishing Email Investigation

A practical cybersecurity investigation project focused on identifying, analysing, and documenting phishing email threats using email header analysis, authentication protocols, URL investigation, and digital evidence.

Project Overview

Phishing is a social engineering attack in which attackers impersonate trusted individuals or organisations to deceive recipients into revealing sensitive information or performing malicious actions.

This project demonstrates a structured approach to phishing email investigation from the perspective of a junior Security Operations Centre (SOC) analyst.

Objectives

* Understand phishing techniques and attack indicators.
* Analyse raw email headers and sender information.
* Investigate SPF, DKIM, and DMARC authentication results.
* Identify suspicious URLs and domains.
* Understand file hashing and Indicators of Compromise (IOCs).
* Document investigation findings and security recommendations.

Investigation Scope

The project will examine three simulated phishing scenarios:

Case ID	Investigation Scenario	      Focus Area
PH-001	Banking impersonation email	  Sender spoofing and email authentication
PH-002	Delivery notification email	  Suspicious URLs and social engineering
PH-003	Business invoice email	      Business Email Compromise (BEC) indicators

Methodology

Each investigation will follow a structured process:

1. Email sample collection
2. Sender and header analysis
3. SPF, DKIM, and DMARC evaluation
4. URL and attachment indicator analysis
5. Evidence documentation
6. Threat assessment and final verdict
7. Security recommendations

Tools and Technologies

* GitHub – Project documentation and version control
* VirusTotal – URL and file reputation analysis
* MXToolbox – DNS and email authentication checks
* Google Sheets – Evidence tracking and analysis
* Google Docs – Investigation reports

Repository Structure

The repository will contain sample email files, individual investigation reports, supporting evidence, and investigation methodology.

Disclaimer

This project is developed for educational and cybersecurity learning purposes.

All initial investigation scenarios will use simulated or authorised sample data. No real personal information, confidential emails, or unauthorised systems will be used.
